# Pesquisa de Satisfação - TudoWeb

Repositório criado para atender à atividade prática da empresa de marketing **TudoWeb**, desenvolvida com o objetivo de coletar, processar e analisar o grau de satisfação dos clientes em relação ao atendimento prestado.

---

## Sobre o Projeto

O programa foi desenvolvido em **Python** utilizando conceitos fundamentais de programação estruturada. Ele automatiza a coleta de dados de nome, idade e avaliação de atendimento de diversos entrevistados, validando as entradas e contabilizando os resultados finais.

### Requisitos Atendidos
1. **Estrutura de Repetição:** Utilização do comando `for` para iterar sobre a quantidade total de entrevistados.
2. **Coleta de Dados:** Solicitação de **nome**, **idade** e **opinião** (`1: EXCELENTE`, `2: BOM`, `3: RUIM`).
3. **Escalabilidade:** Configurado para testes rápidos (10 entrevistados), sendo facilmente ajustable para 50 entrevistados conforme o enunciado.
4. **Estruturas de Decisão:** Uso de `if`, `elif` e blocos de validação (`while` / `try-except`) para verificar as respostas e garantir a integridade dos dados.
5. **Relatório Final:** Exibição da quantidade exata de respostas **EXCELENTE** e **RUIM**.
